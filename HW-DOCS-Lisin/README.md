# Weather MCP — документация проекта

Weather MCP — локальный MCP-сервер на Node.js и TypeScript для получения прогноза и планирования наружных работ с учётом погоды. Данные поступают из Open-Meteo; API-ключ не требуется. Исходный код находится в [weather-mcp](../weather-mcp/), сервер взаимодействует с MCP-клиентом через STDIO.

## Доступные MCP-инструменты

| Инструмент | Назначение и основные параметры |
| --- | --- |
| `get_weather` | Текущая погода и прогноз на 1–7 дней. Параметры: `city`, целое `days`. |
| `assess_weather_risk` | Оценка одного периода работ: `city`, `start_at`, `work_type`, положительное `duration_hours` (допускается дробное). Возвращает риск, факторы и рекомендацию. |
| `compare_weather_windows` | Сравнение ровно двух периодов: `city`, `work_type`, массив `windows` с `start_at` и `duration_hours`. При одинаковом риске победитель не выбирается. |
| `find_safe_weather_window` | Поиск лучшего окна: `city`, `work_type`, `search_start`, `search_end`, целое `duration_hours` от 1 до 8. Возвращает выбранное окно и до трёх альтернатив. |

Для инструментов планирования время задаётся **по Москве**, в формате `YYYY-MM-DDTHH:mm`, независимо от часового пояса города. Начало — не раньше текущего момента, конец — не позднее пяти суток от него. Типы работ: `maintenance`, `installation`, `inspection`. Риски: `LOW`, `MEDIUM`, `HIGH`; рекомендации: `PROCEED`, `REVIEW`, `CANCEL`. Лучшее из доступных окон может иметь риск `HIGH`.

## Установка и запуск

Требуются Node.js 20+ и npm. Для загрузки зависимостей и получения реальной погоды нужен интернет. Команды ниже выполняются в PowerShell из корня проекта:

```powershell
cd .\weather-mcp
npm ci
npm run build
npm start
```

Сервер ожидает обращения MCP-клиента через стандартный ввод. STDOUT используется для MCP/JSON-RPC, сообщения о работе и ошибки направляются в STDERR. Для разработки вместо сборки и `npm start` можно выполнить `npm run dev`.

Для проверки через браузер после сборки запустите из `weather-mcp`:

```powershell
npm run inspect
```

В MCP Inspector подключитесь к серверу и откройте список Tools. Команда Inspector уже настроена на запуск `node dist/index.js`.

## Запуск тестов

Из каталога `weather-mcp`:

```powershell
npm test
```

Сборка TypeScript и все тесты одной командой:

```powershell
npm run ci
```

Проверяются расчёт риска, обработка московского времени, кэш, ошибки Open-Meteo, MCP-инструменты и локальный `/health`. В тестах ответы погодного API подменяются; они не подтверждают доступность реального сервиса.

## Пример использования

В MCP Inspector выберите `get_weather` и передайте аргументы:

```json
{
  "city": "Omsk",
  "days": 3
}
```

При доступном Open-Meteo ответ содержит найденный город и страну, текущую и ощущаемую температуру, ветер, описание погоды и минимальные/максимальные температуры по дням. Фактические значения зависят от прогноза на момент запроса.
